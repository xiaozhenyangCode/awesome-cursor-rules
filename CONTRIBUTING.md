# Contributing

Thanks for helping improve this list. Every entry should save a reader time, so please keep submissions focused and verifiable.

## What fits

- `.cursorrules` / AI coding rules that are reusable across projects (a language, framework or workflow), not project-specific prompts.
- MCP servers that are publicly available, documented and maintained (a commit or release in the last 6 months).

## What doesn't

- Paid-only products without a free tier or open-source component.
- Duplicates of an existing entry, or listings whose main purpose is promotion.

## Format

- Put the entry in the matching section, keep alphabetical order where a section has many entries.
- One line of description in plain English: what it does and why someone would use it. No marketing superlatives.
- For rules, include the snippet in a fenced `markdown` block. For MCP servers, include a minimal config and a link to the source repository.
- Check that every link works.

## Pull requests

- One entry per pull request, with a title like `Add <name>`.
- Say in the description how you have used it, or why it belongs here.

By contributing you agree that your contribution is released under [CC0 1.0](LICENSE).

You can also submit tools directly at [AgentIndex.app](https://agentindex.app/submit).
